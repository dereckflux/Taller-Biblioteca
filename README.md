## 🐺 El expediente · Sobre el taller

Este taller implementa un sistema de gestión bibliotecaria basado en la **colaboración entre clases en Java**[cite: 10, 11]. La clase `Prestamo` recibe un objeto `Libro` completo como parámetro a través de su método `procesarPrestamo`, invocando de manera directa el comportamiento de la clase `Libro` (`prestar()`)[cite: 14]. El sistema gestiona un catálogo robusto de 20 libros, controlando disponibilidades, reintentos de préstamos denegados y devoluciones en tiempo de ejecución[cite: 7, 11].

### 🎯 Objetivos tácticos

- **Aplicar la colaboración de clases**, pasando objetos complejos completos como parámetros de métodos[cite: 11, 14].

## 🩸 Lógica de código · Implementación Java

### 1. `Libro.java` — La entidad base
```java
package Biblioteca;

public class Libro {
    String titulo;
    String autor;
    boolean disponible;

    public Libro(String titulo, String autor) {
        this.titulo = titulo;
        this.autor = autor;
        this.disponible = true; // Todo libro nuevo nace libre
    }

    public void prestar() {
        if (disponible) {
            disponible = false;
            System.out.println("El libro '" + titulo + "' de " + autor + " ha sido prestado.");
        } else {
            System.out.println("El libro '" + titulo + "' no está disponible.");
        }
    }

    public void devolver() {
        disponible = true;
        System.out.println("El libro '" + titulo + "' ha sido devuelto.");
    }

    public void mostrarInfo() {
        System.out.println("- " + titulo + " | " + autor + " | " + (disponible ? "Disponible" : "Prestado"));
    }
}
